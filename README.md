# RH Fiscal Ultra - Ecosistema de Inteligencia Tributaria

**RH Fiscal Ultra** es una infraestructura de software de alta ingeniería diseñada para la gestión fiscal y financiera de **Recursos Humanos De la empresa SL**. Este ecosistema combina precisión matemática, auditoría inmutable y una interfaz de usuario de vanguardia.

## 🚀 Capacidades Core

- **Motor de Inteligencia Multidimensional:** Cálculos avanzados de IRPF, Impuesto de Sociedades, RETA 2026, Cash Flow y Valoración de Empresa.
- **Protocolo PVC-U:** Garantía de integridad sistémica mediante validación continua y evidencia digital SHA-256.
- **Interfaz Glassmorphism:** Diseño inmersivo basado en principios Gestalt para una gestión financiera sin fricciones.
- **Auditoría Certificada:** Generación automatizada de informes profesionales en PDF y Markdown.

## 🛠️ Estructura del Proyecto

```text
rh_tax_calc/
├── logic/              # Núcleo de Inteligencia y Auditoría
│   ├── calculator.py   # Motor de Cálculo Estratégico
│   ├── pvcu_core.py    # Protocolo de Validación Universal
│   └── reporter.py     # Generador de Informes Certificados
├── ui/                 # Capa de Interfaz
│   └── app.py          # UI Glassmorphism Pro
├── main.py             # Punto de Entrada del Sistema
└── IDENTITY_MANIFESTO.md # Manifiesto de Identidad Corporativa
```
